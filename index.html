PDF-Equilibrist

Éditeur PDF de bureau, gratuit et open-source, construit en Python avec PyQt6 et PyMuPDF. Il fonctionne entièrement en local — pas de cloud, pas de télémétrie, pas de compte requis.

PDF‑Equilibrist est disponible pour Windows, Arch Linux (AUR), Ubuntu (PPA) et Fedora (COPR).

Télécharger (Windows) 
yay -S pdf-equilibrist
Voir le paquet sur l'AUR 
sudo add-apt-repository ppa:paulwoisard/pdf-equilibrist
sudo apt update
sudo apt install pdf-equilibrist
Voir le PPA sur Launchpad 
sudo dnf copr enable paullux/PDF-Equilibrist
sudo dnf install pdf-equilibrist
Voir le projet sur COPR
Documentation

Pourquoi PDF‑Equilibrist ?

Les outils PDF en ligne sont pratiques, mais ils imposent l'envoi de vos documents vers des serveurs tiers — parfois sensibles, toujours hors de votre contrôle. PDF‑Equilibrist prend le parti inverse : tout traitement reste sur votre machine.

Conçu pour les environnements où la confidentialité des données est non négociable — cabinets médicaux, études juridiques, PME, administrations — il ne nécessite ni connexion Internet, ni compte utilisateur, ni abonnement.

Construit sur des bibliothèques éprouvées (PyMuPDF, PyQt6), il offre les fonctionnalités essentielles d'un éditeur PDF professionnel dans une interface moderne et réactive.

  • 🔒 100 % local — vos fichiers ne quittent jamais votre machine
  • 🚫 Aucune télémétrie, aucun compte, aucun abonnement
  • 🛡️ Chiffrement AES‑256 intégré
  • ✅ Installation sans droits administrateur
  • 🔍 Code source ouvert et auditable

Fonctionnalités

Tout ce qu'il faut pour lire, modifier, convertir, annoter et protéger vos documents PDF.

Affichage

Zoom, rotation, navigation multi-onglets et multi-pages.

Édition

Modification de texte, filigrane, signatures et tampons.

Annotation

Surlignage, barré, soulignement, zones de texte.

Pages

Insertion, division, fusion, inversion.

Conversion

Word, Excel, PowerPoint, images, Office → PDF, image → PDF, OCR local, traitement par lot.

Protection

Chiffrement et déchiffrement AES-256.

Sécurité & confidentialité

Contrairement aux outils PDF en ligne qui envoient vos fichiers sur des serveurs tiers, PDF-Equilibrist exécute tous ses traitements à 100 % en local.

  • Analyse SAST du code source via Bandit.
  • Vérification des dépendances contre les vulnérabilités connues via l'API OSV.
  • L'outil d'audit est intégré à l'application, accessible en un clic.

Installation

📦 Pour installer la version exécutable Windows (.exe) sans installer Python, téléchargez le dernier installeur dans les Releases.

🐧 Sur Arch Linux et dérivées, disponible sur l'AUR :

yay -S pdf-equilibrist

🐧 Sur Ubuntu et dérivées, disponible via un PPA :

sudo add-apt-repository ppa:paulwoisard/pdf-equilibrist
sudo apt update
sudo apt install pdf-equilibrist

🐧 Sur Fedora et dérivées, disponible via COPR :

sudo dnf copr enable paullux/PDF-Equilibrist
sudo dnf install pdf-equilibrist

Installation depuis les sources (développeurs)

1. Créez un environnement Python compatible (>=3.12).
2. Installez les dépendances :

python -m pip install -r requirements.txt

3. Exécutez l'application :

python src/pdf_equilibrist/main.py

Questions fréquentes

PDF‑Equilibrist envoie-t-il mes fichiers sur Internet ?

Non. Tous les traitements sont effectués localement sur votre machine. Aucun fichier ne quitte votre poste de travail.

PDF‑Equilibrist est-il gratuit ?

Oui, entièrement gratuit et open source, distribué sous licence GNU GPL v3.

PDF‑Equilibrist remplace-t-il Adobe Acrobat ?

Pour de nombreux usages courants — édition, annotation, conversion, protection — oui. Il ne nécessite ni abonnement ni compte.

Quels systèmes d'exploitation sont supportés ?

Windows (installeur .exe), Arch Linux (AUR), Ubuntu (PPA) et Fedora (COPR).

Faut-il des droits administrateur pour l'installer ?

Non. L'installeur Windows s'installe dans le profil utilisateur sans élévation UAC.

Le code source est-il auditable ?

Oui. Le code est publié sur GitHub et les dépendances sont analysées automatiquement contre les vulnérabilités connues.
