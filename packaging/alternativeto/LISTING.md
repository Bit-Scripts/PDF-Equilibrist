## Short description (une ligne)

Free, open-source desktop PDF editor that works entirely offline: edit text, annotate, sign, convert, OCR and encrypt — no cloud, no account, no telemetry.

## Description

PDF-Equilibrist is a free and open-source PDF editor for the desktop (Windows and Linux). Everything runs on your own computer: your documents are never uploaded, there is no account and no telemetry. The only optional network requests are a version check and a vulnerability check, and both can be blocked completely from the Help menu.

What it does:
- Edit existing text block by block, with the original font, size and colour preserved.
- Add text, images, stamps and signature images, placed interactively on the page (drag, resize, rotate).
- Annotate: highlight, strike out, underline, text boxes.
- Organise pages: insert, split, merge, reverse, rotate.
- Convert PDF to Word, Excel, PowerPoint or images, and Office documents or images to PDF, with batch processing.
- Built-in offline OCR (models are bundled, nothing is downloaded) to make scanned PDFs searchable or to convert them to editable Word and Excel files.
- Protect files with AES-256 encryption and add watermarks.
- Careful printing, including very fine CAD-style hairlines.
- Available in English and French.

On Windows it installs per-user without administrator rights. On Linux it is available as an AppImage (a single file, installed in your home folder without root), and as native packages for Arch (AUR), Ubuntu (PPA) and Fedora (COPR).
