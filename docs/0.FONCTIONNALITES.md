# Fonctionnalités — PDF Equilibrist

> Ce que fait le logiciel, expliqué simplement. Sous chaque fonctionnalité, un panneau
> **🛠 Pour les développeurs** (replié par défaut) montre comment elle est implémentée.
> ← [Index](1.INDEX.md) · [Architecture](2.ARCHITECTURE.md) · [Opérations](4.OPERATIONS.md)

**En deux mots** : tout est traité sur votre ordinateur. Vos documents ne sont jamais envoyés
nulle part, il n'y a ni compte ni télémétrie.

---

## Lire et consulter

### Afficher, zoomer, chercher

Ouvrez plusieurs PDF dans des onglets, zoomez de 25 % à 400 % (Ctrl + molette), faites pivoter
la vue, cherchez un mot dans le document. Les miniatures restent visibles à gauche.

<details>
<summary>🛠 Pour les développeurs</summary>

- `core/document.py` : `Document(QObject)` détient l'unique `fitz.Document` ouvert et émet
  `changed` à chaque modification ; viewer et miniatures se rebranchent dessus (`_rebind_doc()`).
- `ui/viewer.py` : `PdfViewer(QScrollArea)` rend les pages via `get_pixmap`.
- `ui/search_bar.py` : `SearchBar` ; `ui/thumbnail_panel.py` : miniatures + glisser-déposer.
- Multi-documents : `MainWindow._documents` (liste) et `_active_idx`.

</details>

### Imprimer

`Ctrl+P` : choix de l'imprimante, des pages, de l'échelle, de l'orientation, du recto-verso,
avec aperçu. Les plans techniques (traits très fins) restent lisibles sur papier.

<details>
<summary>🛠 Pour les développeurs</summary>

- `ui/print_dialog.py` : `PrintDialog` + `print_document()` ; l'impression tourne dans un `QThread`.
- **Windows** : `ui/print_dialog_win32.py` (`win32_print()`) — GDI direct via `ctypes`, rendu à
  `dpi / 2` puis `StretchDIBits HALFTONE` ×2, et overlay vectoriel `_draw_vector_strokes()`
  pour que les hairlines AutoCAD ne disparaissent pas.
- **Linux / macOS** : `_qt_print()` — `QPrinter` / `QPainter` (CUPS), rendu raster simple.
- Détails : [Architecture › Impression](2.ARCHITECTURE.md) et [Opérations](4.OPERATIONS.md).

</details>

## Modifier

### Modifier le texte existant

Cliquez sur un paragraphe pour le réécrire sur place, avec la même police, taille et couleur.

<details>
<summary>🛠 Pour les développeurs</summary>

- `operations/edit.py` : `extract_text_blocks()` (rect, baseline, police, taille, couleur) puis
  `apply_text_edits()` : redaction transparente + `insert_text` à la ligne de base.
- `ui/page_edit_widget.py` : survol / clic bloc par bloc, éditeur positionné au pixel près.
- Les PDF scannés n'ont pas de texte extractible : un message l'indique (voir OCR).

</details>

### Ajouter texte, image, filigrane, signature, tampon

L'élément apparaît sur la page : déplacez-le, redimensionnez-le, faites-le pivoter, puis validez.
Le filigrane s'applique à toutes les pages ; les tampons prédéfinis et l'import de votre
signature (PNG) sont disponibles.

<details>
<summary>🛠 Pour les développeurs</summary>

- `ui/floating_item.py` : `FloatingItem` (drag, coins pour redimensionner, poignée de rotation) ;
  `viewer.show_floating_item(data, page_index, on_commit, on_cancel)` renvoie un `pdf_rect`
  en coordonnées PDF.
- `operations/edit.py` : `add_text()`, `add_image()`, `add_watermark()` ;
  `operations/annotate.py` : `add_stamp()` ; `ui/signature_dialog.py` pour les tampons.

</details>

### Compresser

Réduit la taille du fichier sans changer son apparence.

<details>
<summary>🛠 Pour les développeurs</summary>

- `operations/edit.py` : `compress(doc, save_path)` — sauvegarde PyMuPDF avec nettoyage
  (`garbage`), déflation et compression des flux.

</details>

### Rendre un scan cherchable (OCR)

Reconnaît le texte des pages scannées et l'ajoute en couche invisible : le PDF a le même aspect
mais devient cherchable et copiable. L'OCR fonctionne **hors ligne** : les modèles sont fournis
avec le logiciel, rien n'est téléchargé. La reconnaissance est excellente sur un scan droit d'au moins
200 dpi ; un scan incliné (dès 1 à 2° environ) ou de basse résolution peut donner un texte
incomplet — redressez-le ou rescannez-le si besoin.

<details>
<summary>🛠 Pour les développeurs</summary>

- `operations/ocr.py` : RapidOCR (ONNX Runtime, modèles PP-OCRv6) ; `apply_ocr_to_pdf()` insère le
  texte en `render_mode=3` ; `ocr_to_markdown()` exporte en Markdown.
- Une page est « scannée » si elle n'a aucun texte mais au moins une image (`_is_scanned_page`).
- Les trois `.onnx` sont dans la wheel `rapidocr` ; `_check_models()` lève
  `OcrModelsMissingError` plutôt que de laisser RapidOCR télécharger.
- Test hors-ligne : `tests/test_operations/test_ocr.py` (sockets interdites).

</details>

## Organiser les pages

### Insérer, diviser, fusionner, inverser, extraire

Réorganisez un document : glissez les miniatures, sélectionnez plusieurs pages (Ctrl / Maj + clic)
puis clic droit pour monter, descendre, pivoter, dupliquer, extraire, supprimer ou imprimer.
Toutes ces actions s'annulent avec Ctrl+Z.

<details>
<summary>🛠 Pour les développeurs</summary>

- `operations/pages.py` : `rotate_pages()`, `invert_pages()`, `split_pdf()`, `merge_pdfs()`,
  `insert_page()`, `extract_pages()`, `crop_page()`, `set_page_size()`.
- `ui/thumbnail_panel.py` : `_ThumbList` en `ExtendedSelection`, menu contextuel unique
  (`_on_right_click`) dont chaque action reçoit la liste des pages sélectionnées.
- Annulation : `Document.checkpoint()` avant toute modification, `Document.undo()`.

</details>

## Convertir

### PDF vers Word, Excel, PowerPoint, images, Markdown — et inversement

Exportez vos PDF, ou transformez images et documents Office en PDF. Un traitement par lot
applique une opération à tout un dossier avec une barre de progression.

<details>
<summary>🛠 Pour les développeurs</summary>

- `operations/convert.py` : `to_word()` (pdf2docx), `to_excel()` (pdfplumber + openpyxl),
  `to_powerpoint()` (python-pptx), `to_images()`, `to_markdown()`, `image_to_pdf()`,
  `office_to_pdf()`.
- **Scans** : `to_word()` convertit une copie du document en mémoire dont le texte OCR a été rendu visible
  (`_reveal_ocr_text`). `ocr.ocr_to_excel()` détecte la grille du tableau dans l'image (OpenCV : traits
  horizontaux/verticaux), range chaque texte reconnu dans sa cellule, sans modifier le document ; sans
  bordures, chaque boîte de texte OCR devient une cellule. Le symbole « € », lu de façon instable par le
  modèle, est rétabli par colonne de montants.
- `detect_office_engine()` : Microsoft Office (registre Windows) puis LibreOffice (PATH).
- `ui/batch_dialog.py` : traitement par lot dans un `QThread`.

</details>

## Sécurité et confidentialité

### Rien ne quitte votre ordinateur

Pas de compte, pas de télémétrie. Le logiciel ne peut contacter que deux services, et le dit à
l'écran à chaque fois : GitHub (vérifier qu'une nouvelle version existe) et OSV (vérification
CVE, sur demande). Le menu *Aide › Connexions Internet* bloque tout.

<details>
<summary>🛠 Pour les développeurs</summary>

- `network.py` : **seul** point de sortie réseau (`urlopen()`), `NetworkBlockedError` avant tout
  accès quand l'utilisateur bloque ; `settings.py` : état persistant (`QSettings`).
- Hôtes déclarés dans `network.py`, listés dans `PRIVACY.md` et vérifiés par `tests/test_docs.py`.

</details>

### Audit de sécurité intégré

Depuis l'application : analyse du code source (Bandit) et comparaison des bibliothèques installées
avec la base publique de vulnérabilités OSV.

<details>
<summary>🛠 Pour les développeurs</summary>

- `cve_checker.py` : `get_installed_packages()`, `scan_dependencies()` (API OSV),
  `scan_source_code()` (Bandit) ; interface `ui/cve_dialog.py`.
- La CI (`.github/workflows/checks.yml`) exécute flake8, Bandit et pytest avant tout build ou
  publication : voir [Build](5.BUILD.md) et [Sécurité](6.SECURITE.md).

</details>

### Mises à jour

Le logiciel peut vérifier s'il existe une version plus récente (désactivable, désactivé par défaut
sous Linux où le gestionnaire de paquets s'en charge).

<details>
<summary>🛠 Pour les développeurs</summary>

- `update.py` + `ui/update_dialog.py` ; l'installeur Windows est téléchargé depuis les releases
  GitHub, uniquement sur action de l'utilisateur.

</details>
