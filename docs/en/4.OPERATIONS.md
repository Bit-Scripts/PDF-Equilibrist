# PDF Operations Reference — PDF Equilibrist

> ← [Index](1.INDEX.md) · [Architecture](2.ARCHITECTURE.md) · [Contributing](3.CONTRIBUTING.md) · [Build](5.BUILD.md)

---

Functions in `operations/` are **UI-free** and receive a `fitz.Document`
directly. They modify the document in place (unless stated otherwise).
The calling tab emits `document.changed` after each call.

---

## operations/edit.py

### `extract_text_blocks(doc, page_index) → list[TextBlock]`

Extracts every text span on a page along with its style metadata.

| `TextBlock` field | Type | Description |
|---|---|---|
| `block_id` | int | Unique identifier on the page |
| `rect` | fitz.Rect | Bounding rectangle of the span |
| `origin` | fitz.Point | **Baseline point** for `insert_text()` |
| `text` | str | Current text content |
| `fontsize` | float | Size in PDF points |
| `color` | tuple(r,g,b) | Normalized color, 0–1 |
| `fontname` | str | Original font name |
| `font_buffer` | bytes\|None | Embedded font (for faithful reinsertion) |

> ⚠ Returns `[]` if the page is an image (scanned PDF with no text layer).

---

### `apply_text_edits(doc, page_index, original_blocks, edited_texts)`

Applies text modifications on a page in two passes:

1. **Redaction**: `add_redact_annot(rect, fill=None)` + `apply_redactions()`
   → removes the original text without leaving a white rectangle
2. **Reinsertion**: `insert_text(origin, new_text, ...)` at the exact baseline point

Only blocks whose text changed (`edited_texts[bid] != original_blocks[bid].text`)
are processed.

**Parameters**:
- `original_blocks`: list produced by `extract_text_blocks()`
- `edited_texts`: `{block_id: new_text}` — modified blocks only

---

### `compress(doc, save_path)`

Saves with maximum compression (garbage=4, deflate=True).
Does not modify the in-memory document — writes a new file.

---

### `add_watermark(doc, text, color=(0.6,0.6,0.6))`

Inserts a diagonal text (45°, fontsize=48) centered on every page.
Centering is approximate (13 pts/character).

---

### `add_text(doc, page_index, text, point, fontsize=12, color=(0,0,0))`

Inserts free text at `point` (PDF coordinates, baseline point).

---

### `add_image(doc, page_index, image_path, rect)`

Inserts an image into the `rect` rectangle (stretched to fill it).

---

## operations/pages.py

### `rotate_pages(doc, angle, page_indices=None)`

Additive rotation (`rotation + angle) % 360`) on the specified pages.
Valid angles: +90 (right), -90 (left), 180.

---

### `invert_pages(doc) → fitz.Document`

Returns a **new** document with pages in reverse order.
The original is not modified.
The calling tab must close the old one and assign the new one before
emitting `changed`.

---

### `split_pdf(doc, output_dir) → list[Path]`

One PDF per page in `output_dir`. Returns the created paths.

---

### `merge_pdfs(paths) → fitz.Document`

Concatenates several PDFs into a new in-memory document (not saved).

---

### `insert_page(doc, after_index, src_path=None)`

- `src_path=None` → inserts a blank page (A4 by default)
- `src_path` provided → inserts every page from the source PDF

---

### `crop_page(doc, page_index, rect)`

Sets the CropBox (visible area) — non-destructive, the content remains in the PDF.

---

### `set_page_size(doc, page_index, width, height)`

Modifies the MediaBox. Standard dimensions in PDF points:
- A4 portrait  : 595 × 842
- A4 landscape : 842 × 595
- Letter       : 612 × 792

---

## operations/annotate.py

All functions return the created `fitz.Annot` object.
Annotations are PDF objects distinct from the page content.

### `highlight(page, quads)`
Yellow highlight. `quads` = `[fitz.Rect(bbox).quad for word in words]`.

### `strikeout(page, quads)`
Strikethrough (horizontal line through the middle of the text).

### `underline(page, quads)`
Underline beneath the text.

### `add_text_box(page, rect, text, fontsize=11, color=(0,0,0))`
FreeText box with a pale yellow background and a golden border.

### `add_stamp(page, rect, stamp_id=0)`
Predefined PDF stamp (0=Draft, 1=Approved, 2=Experimental…).

## operations/convert.py

### `detect_office_engine() → 'msoffice' | 'libreoffice' | None`

Detects the available engine:
1. MS Office → registry `HKLM\SOFTWARE\Microsoft\...\App Paths\WINWORD.EXE`
2. LibreOffice → standard paths + `shutil.which("soffice")`

---

### `office_to_pdf(input_path, output_path) → Path`

Converts an Office file (.docx/.xlsx/.pptx) to PDF.

| Engine | Mechanism |
|---|---|
| MS Office | `docx2pdf.convert()` (COM automation) |
| LibreOffice | `soffice --headless --convert-to pdf` |

Raises `RuntimeError` if no engine is available.

---

### `to_images(doc, output_dir, zoom=2.0, fmt='png') → list[Path]`

One image file per page. Recommended zoom: 2.0 (144 dpi).

---

### `to_word(doc, src_path, output_path) → Path`

Uses `pdf2docx.Converter`. Requires the **file path** (not the `fitz.Document`).

---

### `to_excel(doc, output_path) → Path`

Extracts tables via `pdfplumber`. One sheet per page.
Only effective on PDFs with visibly bordered tables.

---

### `to_powerpoint(doc, output_path, zoom=1.5) → Path`

One slide per page (rasterized image). Text is not editable in PowerPoint.

---

### `image_to_pdf(image_paths, output_path) → Path`

Each image → one A4 page (595×842 pts). The image is stretched to fill the page.

---

## operations/protect.py

### `encrypt(doc, save_path, user_password, owner_password='')`

AES-256 encryption into a **new file**. Permissions granted:
`PDF_PERM_PRINT | PDF_PERM_COPY`.
The source document remains unchanged in memory.

---

### `decrypt(doc, password) → bool`

Calls `doc.authenticate(password)`. Returns `True` on success.
Decryption is done **in place** (unlocks in memory, no file is created).

---

### `is_encrypted(doc) → bool`

Checks whether the document requires a password.

---

## ui/print_dialog.py

### `print_document(document, parent=None) → bool`

Opens the Windows print dialog and sends the document to the printer.

| Step | Detail |
|---|---|
| QPrinter | HighResolution — uses the printer's real DPI (600–1200) |
| QPrintDialog | System dialog: printer selection, page range, copies, orientation |
| Zoom | `dpi / 72` — 1 PDF pt = 1/72 inch, independent of the display zoom |
| Rendering | `fitz.Page.get_pixmap(matrix)` at printer resolution |
| Sending | `QPainter.drawPixmap(page_rect, pixmap)` for each page |

Returns `True` if printed, `False` if cancelled or the document is closed.
Shortcut: `Ctrl+P` — also accessible via File → Print and the ribbon button.
