## Prerequisites

- The `Equilibrist` conda environment set up (see [CONTRIBUTING](CONTRIBUTING.md))
- PyInstaller installed (`pip install pyinstaller`)
- `assets/logo/PDF-Equilibrist-logo.ico` present (multi-resolution)
- `assets/Splashscreen.jpg` present (splash screen image)

---

## Step 1 — Prepare the assets

```powershell
conda activate D:\Developpement\CONDA\envs\Equilibrist
cd D:\Developpement\PDF-Equilibrist
python tools/prepare_build.py
```

This script:
- Checks that the `.ico` file is present (does not regenerate it — see below)
- Converts `assets/Splashscreen.jpg` → `assets/splash.png` (600×338 px)

> ℹ️ The provided multi-resolution `.ico` file is kept as-is.
> If you need to regenerate it from the PNG, use `tools/make_ico.py`.

---

## Step 2 — Compile the exe

```powershell
pyinstaller PDF-Equilibrist.spec
```

The exe is generated at `dist/PDF-Equilibrist.exe` (single file, ~80-120 MB).

### Useful options

```powershell
# Force a full rebuild (ignore the cache)
pyinstaller PDF-Equilibrist.spec --clean --noconfirm

# With a debug console (to diagnose startup crashes)
# Temporarily change in the spec: console=True
pyinstaller PDF-Equilibrist.spec
```

---

## Spec file structure

The `PDF-Equilibrist.spec` file configures:

| Section | Description |
|---|---|
| `datas` | Bundled assets (logo, buttons, splash, Python sources) |
| `hiddenimports` | Modules not detected automatically (winreg, ctypes, PyQt6.QtPrintSupport…) |
| `excludes` | Modules to exclude to reduce size (tkinter, matplotlib…) |
| `splash` | PyInstaller splash screen (shown before Python starts) |
| `upx_exclude` | DLLs that must not be compressed (zlib, vcruntime, Qt6…) |

### Why `upx_exclude` matters

UPX compresses DLLs to shrink the exe. Some critical DLLs (zlib, vcruntime,
Qt6 DLLs) crash on startup if compressed. The spec's `upx_exclude` list
excludes these DLLs from compression.

## Step 3 — Build the NSIS installer

### NSIS prerequisites

- NSIS 3.x installed (`C:\Program Files (x86)\NSIS\`)
- BMP images present:
  - `assets/installer/wizard_banner.bmp` — 164×314 px (Welcome/Finish page)
  - `assets/installer/wizard_header.bmp` — 150×57 px (inner pages header)

### Compiling

```powershell
# Via PATH if NSIS is on PATH
makensis installer\PDF-Equilibrist.nsi

# Full path if NSIS is not on PATH
& "C:\Program Files (x86)\NSIS\makensis.exe" installer\PDF-Equilibrist.nsi

# → installer\Output\PDF-Equilibrist-Setup.exe
```

### What the installer does

- Installs **without administrator rights** (HKCU, `%LocalAppData%`)
- Start Menu shortcut
- `.pdf` association → "Open with PDF Equilibrist"
- Entry in "Programs and Features" with a clean uninstaller
- Optional desktop shortcut (checkbox)

### Injecting the version from the git tag

The NSIS script supports a version parameter for CI/CD:

```powershell
makensis /DAPP_VERSION=1.2.3 installer\PDF-Equilibrist.nsi
```

## CI/CD — Automatic build on GitHub tag

`.github/workflows/release.yml` — triggered by a `v*` tag or manually
(`workflow_dispatch`):

```
tag v0.1.4
    └── release.yml
         ├── Resolve version         → extracts "0.1.4" from the tag or the input
         ├── setup-python 3.12
         ├── pip install -r requirements.txt + pyinstaller
         ├── python tools/prepare_build.py
         ├── pyinstaller PDF-Equilibrist.spec
         ├── choco install nsis
         ├── makensis /DAPP_VERSION=0.1.4  → installer\Output\PDF-Equilibrist-Setup.exe
         ├── Sign installer (if SIGNING_CERT_PFX_B64 is configured)
         └── softprops/action-gh-release@v2
              ├── generate_release_notes: true   ← auto changelog from commits
              └── files: PDF-Equilibrist-Setup.exe
```

Triggered by: `git tag v1.2.3 && git push --tags`

**Automatic release notes**: `generate_release_notes: true` generates the
changelog from commits and pull requests since the previous tag.

## Signing the installer (optional)

Code signing removes the Windows SmartScreen warning and proves the origin
of the executable. It is configured via two GitHub secrets:

| GitHub secret | Content |
|---|---|
| `SIGNING_CERT_PFX_B64` | Base64-encoded PFX certificate |
| `SIGNING_CERT_PASSWORD` | PFX password |

### Encoding the PFX certificate

```powershell
$bytes = [IO.File]::ReadAllBytes("my-certificate.pfx")
[Convert]::ToBase64String($bytes) | Set-Clipboard
# Paste into GitHub → Settings → Secrets → SIGNING_CERT_PFX_B64
```

### Workflow behavior

- If `SIGNING_CERT_PFX_B64` is missing or empty → the signing step is
  silently skipped (the build continues without error).
- If `signtool.exe` cannot be found in the Windows Kits → same behavior.
- The signed installer replaces the unsigned one before upload to GitHub Releases.

### Local signing (outside CI)

```powershell
signtool sign /f my-certificate.pfx /p mypassword /fd SHA256 `
    /tr http://timestamp.digicert.com /td SHA256 `
    installer\Output\PDF-Equilibrist-Setup.exe
```

## Windows "Open with..." registration

After the first installation:

```powershell
# Automatic registration via Python (HKCU — no admin rights)
python tools/register_filetype.py --exe "D:\...\dist\PDF-Equilibrist.exe"

# Unregistration
python tools/register_filetype.py --exe "D:\...\dist\PDF-Equilibrist.exe" --unregister
```

Registration is also performed **automatically** on the first launch of the
compiled exe (via `registration.auto_register()` in `main.py`).

---

## Double-click and "Open with..."

Once registered, the exe can be launched with a PDF path as an argument:

```cmd
PDF-Equilibrist.exe "C:\Documents\report.pdf"
```

Windows automatically passes the path via `sys.argv[1]` on a double-click or
an "Open with..." action. `main.py` opens the file in a tab after the window
has been initialized.

To set PDF Equilibrist as the **default application** for PDFs:
`Windows Settings → Apps → Default apps → .pdf`

## Build troubleshooting

### The exe crashes on startup (zlib / vcruntime)

Check that `upx_exclude` in the spec contains:
```
"zlib1.dll", "vcruntime140.dll", "msvcp140.dll",
"Qt6Core.dll", "Qt6Gui.dll", "Qt6Widgets.dll"
```

### Missing module at runtime (ImportError)

Add the module to the spec's `hiddenimports` and rebuild.

### Assets not found (FileNotFoundError)

Check that the folder is included in the spec's `datas`.
Check that the code uses `resource_path()` (no hardcoded relative paths).

### Antivirus blocks the exe

PyInstaller onefile exes are sometimes flagged (false positive).
Solutions: sign the exe (EV certificate), submit it to the antivirus
whitelist, or use `onedir` mode (folder + exe), which is less prone to
false positives.

- [ ] `installer\Output\PDF-Equilibrist-Setup.exe` installs and uninstalls cleanly

- [ ] Clear the Windows icon cache if the icon isn't up to date
