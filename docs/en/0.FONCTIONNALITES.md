# Features — PDF Equilibrist

> What the software does, in plain words. Under each feature, a collapsed
> **🛠 For developers** panel shows how it is implemented.
> ← [Index](1.INDEX.md) · [Architecture](2.ARCHITECTURE.md) · [Operations](4.OPERATIONS.md)

**In short**: everything is processed on your computer. Your documents are never sent
anywhere, and there is no account and no telemetry.

---

## Read and browse

### View, zoom, search

Open several PDFs in tabs, zoom from 25% to 400% (Ctrl + wheel), rotate the view, search for a
word in the document. Thumbnails stay visible on the left.

<details>
<summary>🛠 For developers</summary>

- `core/document.py`: `Document(QObject)` owns the single open `fitz.Document` and emits
  `changed` on every modification; the viewer and thumbnails rebind to it (`_rebind_doc()`).
- `ui/viewer.py`: `PdfViewer(QScrollArea)` renders pages through `get_pixmap`.
- `ui/search_bar.py`: `SearchBar`; `ui/thumbnail_panel.py`: thumbnails + drag & drop.
- Multi-document: `MainWindow._documents` (list) and `_active_idx`.

</details>

### Print

`Ctrl+P`: choose the printer, pages, scaling, orientation and duplex, with a preview. Technical
drawings (very thin lines) stay readable on paper.

<details>
<summary>🛠 For developers</summary>

- `ui/print_dialog.py`: `PrintDialog` + `print_document()`; printing runs in a `QThread`.
- **Windows**: `ui/print_dialog_win32.py` (`win32_print()`) — direct GDI through `ctypes`, rendering
  at `dpi / 2` then `StretchDIBits HALFTONE` ×2, plus the vector overlay `_draw_vector_strokes()`
  so AutoCAD hairlines do not vanish.
- **Linux / macOS**: `_qt_print()` — `QPrinter` / `QPainter` (CUPS), plain raster rendering.
- Details: [Architecture › Printing](2.ARCHITECTURE.md) and [Operations](4.OPERATIONS.md).

</details>

## Edit

### Edit existing text

Click a paragraph to rewrite it in place, with the same font, size and colour.

<details>
<summary>🛠 For developers</summary>

- `operations/edit.py`: `extract_text_blocks()` (rect, baseline, font, size, colour) then
  `apply_text_edits()`: transparent redaction + `insert_text` on the baseline.
- `ui/page_edit_widget.py`: block-by-block hover / click, editor positioned pixel-perfect.
- Scanned PDFs have no extractable text: a message says so (see OCR).

</details>

### Add text, image, watermark, signature, stamp

The element appears on the page: move it, resize it, rotate it, then confirm. The watermark applies
to every page; predefined stamps and import of your signature (PNG) are available.

<details>
<summary>🛠 For developers</summary>

- `ui/floating_item.py`: `FloatingItem` (drag, corners to resize, rotation handle);
  `viewer.show_floating_item(data, page_index, on_commit, on_cancel)` returns a `pdf_rect` in
  PDF coordinates.
- `operations/edit.py`: `add_text()`, `add_image()`, `add_watermark()`;
  `operations/annotate.py`: `add_stamp()`; `ui/signature_dialog.py` for stamps.

</details>

### Compress

Shrinks the file without changing its appearance.

<details>
<summary>🛠 For developers</summary>

- `operations/edit.py`: `compress(doc, save_path)` — PyMuPDF save with cleanup (`garbage`),
  deflate, and compression of streams, images and fonts.

</details>

### Make a scan searchable (OCR)

Recognises the text of scanned pages and adds it as an invisible layer: the PDF looks the same but
becomes searchable and copyable. OCR works **offline**: the models ship with the software and
nothing is downloaded.

<details>
<summary>🛠 For developers</summary>

- `operations/ocr.py`: RapidOCR (ONNX Runtime, PP-OCRv6 models); `apply_ocr_to_pdf()` inserts the
  text with `render_mode=3`; `ocr_to_markdown()` exports to Markdown.
- A page is "scanned" when it has no text but at least one image (`_is_scanned_page`).
- The three `.onnx` files are inside the `rapidocr` wheel; `_check_models()` raises
  `OcrModelsMissingError` rather than letting RapidOCR download anything.
- Offline test: `tests/test_operations/test_ocr.py` (sockets forbidden).

</details>

## Organise pages

### Insert, split, merge, reverse, extract

Rearrange a document: drag thumbnails, select several pages (Ctrl / Shift + click) then right-click to
move up, move down, rotate, duplicate, extract, delete or print. All of this can be undone with Ctrl+Z.

<details>
<summary>🛠 For developers</summary>

- `operations/pages.py`: `rotate_pages()`, `invert_pages()`, `split_pdf()`, `merge_pdfs()`,
  `insert_page()`, `extract_pages()`, `crop_page()`, `set_page_size()`.
- `ui/thumbnail_panel.py`: `_ThumbList` in `ExtendedSelection`, a single context menu
  (`_on_right_click`) whose actions all receive the list of selected pages.
- Undo: `Document.checkpoint()` before any modification, `Document.undo()`.

</details>

## Convert

### PDF to Word, Excel, PowerPoint, images, Markdown — and back

Export your PDFs, or turn images and Office documents into PDF. Batch processing applies an
operation to a whole folder with a progress bar.

<details>
<summary>🛠 For developers</summary>

- `operations/convert.py`: `to_word()` (pdf2docx), `to_excel()` (pdfplumber + openpyxl),
  `to_powerpoint()` (python-pptx), `to_images()`, `to_markdown()`, `image_to_pdf()`,
  `office_to_pdf()`.
- `detect_office_engine()`: Microsoft Office (Windows registry) then LibreOffice (PATH).
- `ui/batch_dialog.py`: batch processing in a `QThread`.

</details>

## Security and privacy

### Nothing leaves your computer

No account, no telemetry. The software can only contact two services, and says so on screen every
time: GitHub (to check whether a new version exists) and OSV (CVE check, on request). The
*Help › Internet connections* menu blocks everything.

<details>
<summary>🛠 For developers</summary>

- `network.py`: the **only** network exit point (`urlopen()`), raising `NetworkBlockedError` before
  any access when the user has blocked connections; `settings.py`: persistent state (`QSettings`).
- Hosts are declared in `network.py`, listed in `PRIVACY.md` and checked by `tests/test_docs.py`.

</details>

### Built-in security audit

From within the application: source-code analysis (Bandit) and comparison of the installed libraries
with the public OSV vulnerability database.

<details>
<summary>🛠 For developers</summary>

- `cve_checker.py`: `get_installed_packages()`, `scan_dependencies()` (OSV API),
  `scan_source_code()` (Bandit); UI in `ui/cve_dialog.py`.
- CI (`.github/workflows/checks.yml`) runs flake8, Bandit and pytest before any build or
  publication: see [Build](5.BUILD.md) and [Security](6.SECURITE.md).

</details>

### Updates

The software can check whether a newer version exists (can be turned off; off by default on Linux,
where the package manager handles updates).

<details>
<summary>🛠 For developers</summary>

- `update.py` + `ui/update_dialog.py`; the Windows installer is downloaded from the GitHub
  releases, only on user action.

</details>
