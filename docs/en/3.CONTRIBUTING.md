## Setting up the environment

```powershell
# Clone the project
git clone <url> PDF-Equilibrist
cd PDF-Equilibrist

# Restore the conda environment
conda env create -p D:\Developpement\CONDA\envs\Equilibrist -f environment.yml

# Activate it
conda activate D:\Developpement\CONDA\envs\Equilibrist

# Install the project in editable mode
pip install -e .
```

---

## Running the application

```powershell
python src/pdf_equilibrist/main.py
```

The splash screen appears, followed by the main window.
In dev mode, `resource_path()` resolves assets from the project root.

## Structure of a ribbon tab

Each ribbon tab is a `QWidget` under `ui/tabs/`. To create one:

```python
# ui/tabs/tab_exemple.py
"""
tabs/tab_exemple.py — "Example" tab
Short description of the tab's role.
"""
from PyQt6.QtWidgets import QWidget, QHBoxLayout
from pdf_equilibrist.ui.widgets import RibbonButton, RibbonGroup
from pdf_equilibrist.core.document import Document


class TabExemple(QWidget):
    def __init__(self, document: Document, viewer=None):
        super().__init__()
        self.document = document   # reference rebound by MainWindow._rebind_doc()
        self.viewer   = viewer

        layout = QHBoxLayout(self)
        layout.setContentsMargins(6, 0, 6, 0)
        layout.setSpacing(0)

        # Button group
        self._btn_action = RibbonButton("⊕", "Action")
        grp = RibbonGroup("My group")
        grp.add(self._btn_action)
        layout.addWidget(grp)
        layout.addStretch()

        self._btn_action.clicked.connect(self._do_action)

    def _do_action(self):
        if not self.document.is_open:
            return
        # Call into operations/
        from pdf_equilibrist.operations.edit import add_text
        import fitz
        add_text(self.document.fitz_doc, 0, "Hello", fitz.Point(100, 100))
        self.document.changed.emit()   # ALWAYS emit after a modification
```

Then in `main_window.py`:
```python
from pdf_equilibrist.ui.tabs.tab_exemple import TabExemple

self._tab_exemple = TabExemple(self._current_doc, self.viewer)
# Add it to the ribbon_tabbar and ribbon_stack
# Add it to the list in _rebind_doc()
```

## Adding a PDF operation

Functions in `operations/` are **pure functions** (no UI):

```python
# operations/edit.py (example addition)
def add_border(doc: fitz.Document, page_index: int, color: tuple = (1, 0, 0)):
    """
    Adds a red border to a page.

    Parameters
    ----------
    doc : fitz.Document
        Document to modify in place.
    page_index : int
        0-based page number.
    color : tuple
        Normalized RGB color, 0–1.
    """
    page = doc[page_index]
    page.draw_rect(page.rect, color=color, width=2)
```

**Rules**:
- No PyQt6 imports in `operations/`
- Return standard Python types (Path, list, bool…)
- Document parameters and edge cases
- The calling tab handles the UI (dialogs, progress) and emits `document.changed`

## Naming convention

| Element | Convention | Example |
|---|---|---|
| Files | `snake_case` | `tab_modifier.py` |
| Classes | `PascalCase` | `FloatingItem` |
| Public methods | `snake_case` | `enter_edit_mode()` |
| Private methods | `_snake_case` | `_on_doc_changed()` |
| Qt signals | `snake_case` | `zoom_changed` |
| Constants | `UPPER_SNAKE` | `ACCENT`, `THUMB_H` |

## Contribution rules

### 1. Qt signals
Always emit `document.changed` after modifying the `fitz.Document`.
Never call `viewer.refresh()` or `thumbs.rebuild()` directly from a tab.

### 2. Asset paths
Use `resource_path()` from `utils.py` for every asset file access.
Never use hardcoded relative paths.

### 3. UI-free operations
Functions in `operations/` must not import PyQt6.
If an operation needs to report information back to the UI, do it via the
return value (not via internal dialogs).

### 4. Error handling
Wrap potentially failing operations in `try/except` in the tab (not in the
operation itself), and display the error via `show_error()`.

### 5. Multi-document rebinding
If a tab stores internal state tied to the document (e.g. `_edit_blocks` in
`tab_modifier`), clear it in a method triggered by `document.changed` or
during rebinding.

## Adding a reusable dialog

In `ui/dialogs.py`:

```python
def ask_my_param(parent, title: str) -> str | None:
    """Returns the entered value, or None if cancelled."""
    dlg = QDialog(parent)
    dlg.setWindowTitle(title)
    dlg.setStyleSheet(DIALOG_STYLE)
    layout = QVBoxLayout(dlg)
    # ... build the dialog
    _ok_cancel(dlg, layout)   # adds the OK/Cancel buttons
    return result if dlg.exec() == QDialog.DialogCode.Accepted else None
```

```powershell

pytest tests/

# A specific test
pytest tests/test_operations/test_edit.py::test_extract_text_blocks -v
```
